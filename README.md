# Miracle Omugbe — Portfolio

GitHub Pages-ready portfolio for Miracle Omugbe.

## Upload to GitHub
1. Create/open your public portfolio repository.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. Commit the changes.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and `/ (root)`, then save.
7. GitHub will provide the live portfolio URL.

Keep the `assets` folder beside `index.html`; the website uses relative paths such as `assets/miracle.jpg`.
